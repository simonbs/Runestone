# Syntax highlight examples

Each image compares individual `Theme` callbacks (top) with a complete
`HighlightStyle` (bottom), using identical text and layout.

- `token-backgrounds.png`: comment, string, and tag backgrounds.
- `nested-style-reset.png`: an empty style restores default text color/font and clears the enclosing shadow.
- `font-weight-compatibility.png`: both APIs preserve a custom semibold font.
